Season 50 contestant images

Place contestant photos for Season 50 in this folder.

Name suggestions:
  - Use slugified filenames, e.g. alice-raptors.jpg, ben-tigers.webp
  - Prefer JPEG or WEBP, ~800×1000 px, optimized (50–200KB)

Example path (from project root):
  media/cast/season-50/alice-raptors.jpg

Notes:
  - Django serves media files from MEDIA_ROOT — ensure your settings have `MEDIA_ROOT` and `MEDIA_URL` set for development.
  - To reference uploaded images in the admin or models, use the `photo` ImageField associated with the Contestant model.
